## About The Project

This is a dynamic, fully responsive, and modern Admin Dashboard built from scratch using clean **HTML5**, modern **CSS3**, and **TypeScript** (without relying on external JS libraries). The layout is tailored to deliver an optimal user experience with smooth interactive UI components and interactive state management.

### Key Technical Implementations:

- **Interactive Sidebar Navigation:** Built with TypeScript to handle smooth collapse, expand, and overlay behavior, while automatically adjusting the main layout grid dynamically.
- **Smart Search Component:** A sleek expandable search bar that toggles smooth input field animation upon clicking the search icon.
- **Custom Dynamic UI Logic:** Advanced DOM manipulation and state management strictly using strongly-typed **TypeScript** logic.
- **Modern CSS Architecture:** Built using CSS Grid, Flexbox, and native CSS Variables (`:root`) for dark-mode palette consistency.
- **Clean & Scalable Codebase:** Designed with maintainability and scalable front-end best practices in mind.

# لوحة تحكم التحليلات والإدارة (Admin Dashboard)

لوحة تحكم إدارية حديثة وتفاعلية بالكامل، متجاوبة مع كافة الشاشات، تم بناؤها من الصفر باستخدام **HTML5** نظيفة، و **CSS3** حديثة، ولغة **TypeScript** (بدون الاعتماد على أي مكتبات جافاسكريبت خارجية). تم تصميم الهيكل لتقديم أفضل تجربة مستخدم ممكنة مع مكونات تفاعلية وإدارة سلسة لحالات الواجهة (State Management).

## أبرز التطبيقات البرمجية والتقنية

- **قائمة جانبية تفاعلية (Interactive Sidebar):** تم بناؤها باستخدام TypeScript للتحكم في الإخفاء، الظهور، والطفو فوق المحتوى (Overlay)، مع إعادة ضبط أبعاد الهيكل الرئيسي تلقائياً وبشكل ديناميكي.
- **مكون بحث ذكي (Smart Search):** شريط بحث مدمج يتمدد وينكمش عند الضغط على أيقونة البحث مع حركة انسيابية.
- **منطق برمجي مخصص للواجهة:** التعامل المباشر مع عناصر الـ DOM وإدارة الحالات بالاعتماد الكامل على نمط البرمجة القوي لـ TypeScript.
- **هيكلة CSS حديثة:** بناء الواجهة باستخدام CSS Grid و Flexbox والمتغيرات المباشرة (`:root`) لضمان تناسق ألوان النمط الداكن (Dark Mode).
- **كود نظيف وقابل للتطوير:** تم مراعاة أفضل الممارسات في تطوير الواجهات الأمامية لتسهيل الصيانة والتطوير مستقبلاً.

## التقنيات المستخدمة (Tech Stack)

- **HTML5:** هيكلة دلالية ونظيفة للمحتوى.
- **CSS3:** استخدام CSS Grid، Flexbox، والمتغيرات المباشرة (`:root`) للتجاوب والتنسيق.
- **TypeScript:** كتابة المنطق البرمجي، التفاعل، وإدارة حالات الواجهة.
- **FontAwesome:** مكتبة أيقونات لتحسين الواجهة وتسهيل التنقل.
